# Fantasy Frontier · NFL DFS Lab (Beta)

A Sports Labs product: DraftKings NFL daily fantasy research, value plays and a lineup builder for the Thursday, Sunday main and Monday slates.

Live: https://fantasyfrontier.sportslabshq.com/

This repo is the public website only. The data in `data/` is display-ready output published by a private Sports Labs engine. Data comes from free public sources (DraftKings salaries, nflverse, ESPN, Open-Meteo).
